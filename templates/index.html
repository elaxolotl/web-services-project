Efficient management of detained goods and auctions

Gavel API provides a secure platform for managing detained goods and conducting auctions. Designed for customs officers and buyers, the API ensures efficient handling of goods, bids, and user roles.


  • Goods management

    Add, update, and delete detained goods with detailed information, including perishable status, expiry dates, and financial details.


  • Secure auctions

    Place bids on goods, view bid history, and manage your bids with role-based access control.


  • User authentication

    Secure user signup, login, and role-based access to ensure only authorized users can perform specific actions.


  • Real-Time Updates

    Stay informed with real-time updates on goods status, bid values, and auction outcomes.
